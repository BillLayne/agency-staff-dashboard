# Agency Staff Dashboard

Separate staff-only dashboard for Bill Layne Insurance with Unified Search and three launcher sections:
- Operations
- Documents & Forms
- Property & Coverage

Unified Search includes the same 17-company built-in carrier and workers compensation directory used by the agent Agency Command Center. Staff can search, copy, add, edit, remove, back up, and restore contact details. Staff additions and corrections save automatically in that browser; the Backup control downloads a portable JSON copy. Bill's private saved additions and corrections are transferred with a backup file kept outside this public repository.

This app intentionally excludes Gmail Engineering and Quick Image Links / Imgur.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
